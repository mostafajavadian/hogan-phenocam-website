Methodology

The science and engineering behind a zero-cost, serverless phenocam pipeline.

Vegetation indices

Every captured frame is decomposed into its red, green, and blue channels. Four chromatic indices are then computed over the pixels inside a hand-drawn canopy region-of-interest (ROI) mask, which excludes brick buildings, sky, and pavement from the signal.

GCC = G / (R + G + B)
RCC = R / (R + G + B)
BCC = B / (R + G + B)
ExG = 2G − R − B

GCC is the primary greenness signal used to track canopy health and seasonal transitions — it rises during spring green-up, plateaus at peak summer canopy, and falls during autumn senescence. RCC conversely tracks reddening (useful for autumn color change), while ExG provides a channel-difference index that's less sensitive to overall brightness than GCC alone.

Outlier detection

Lighting artifacts — glare, fog, raindrops on the lens, motion blur — can produce spurious readings. Rather than a fixed threshold, the pipeline recomputes an interquartile-range (IQR) fence independently for each calendar day:

Q1, Q3 = 25th/75th percentile of gcc_90th for the day IQR = Q3 − Q1 flag if value < Q1 − 1.5·IQR or value > Q3 + 1.5·IQR

Days need at least 4 readings before fencing is applied. Flagged rows are retained in the dataset (never deleted) and marked is_outlier = 1, so the dashboard can show or hide them on demand — see the Dashboard toggle.

Daylight filtering

Each capture is timestamped against solar elevation at Worcester, MA (42.2626°N, 71.8023°W). Frames captured when the sun is below 5° elevation are logged as empty rows rather than analyzed, since low-light frames carry no reliable phenological signal but the timestamp is still useful for gap tracking.

Pipeline architecture

Fully serverless — a scheduled GitHub Actions job is the only compute this project uses.

Request lifecycle

  • 1

    Trigger

    A cron-scheduled workflow wakes every 30 minutes and checks out the repository.

  • 2

    Stream interception

    A headless Chromium browser loads the public HDOnTap webcam page and listens for the live HLS playlist request. That request sits behind an ad system that doesn't always resolve in time, so if it doesn't appear, the pipeline instead grabs HDOnTap's own periodically-refreshed snapshot thumbnail for this camera from the same page load.

  • 3

    Frame extraction

    OpenCV opens the stream URL directly and reads a single video frame.

  • 4

    Solar-elevation gate

    If the sun is below 5° over Worcester, MA, the frame is skipped and an empty timestamp row is logged instead.

  • 5

    Index calculation

    The canopy ROI mask isolates vegetation pixels; GCC, RCC, BCC, and ExG are computed and appended to phenocam_data.csv.

  • 6

    Outlier re-scan

    The full day's readings are re-evaluated with the IQR method so flags stay consistent as new data arrives.

  • 7

    Publish

    The workflow commits the updated CSV and annotated snapshot back to the repository; GitHub Pages serves the static dashboard directly from the same repo — no server, no database.

Tech stack

Python & OpenCV

Frame decoding, color-channel math, and ROI masking.

Playwright

Headless-browser network interception for the live stream URL.

GitHub Actions

Cron-scheduled, serverless compute — zero hosting cost.

Chart.js

Interactive, zoomable time-series & seasonal-overlay charts.

Pandas & NumPy

Daily IQR outlier detection and time-series bookkeeping.

GitHub Pages

Static hosting for this dashboard, deployed straight from the repo.
